# Tamanna Birthday Surprise

A romantic, mobile-friendly interactive birthday website.

## Run locally
Open `index.html` in a browser.

## Customize
All main text is in `index.html`.
Colors, fonts and animations are in `style.css`.
Interactions are in `script.js`.

## Hosting
Upload the three files (`index.html`, `style.css`, `script.js`) to GitHub, then deploy the repository on Vercel or GitHub Pages.

No backend or environment variables are required.
